# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Read it there; it applies to all spaces this project uses (issues, pull requests, discussions) and when someone represents the
project in public.

In short: be respectful, welcome different viewpoints and experience levels, give and accept constructive feedback
gracefully, and focus on what is best for the project and the people using it. Harassment, personal attacks, and
publishing others' private information are not acceptable.

## Reporting

If you experience or witness unacceptable behaviour, report it privately to the maintainer through a GitHub private
message or the contact options on the maintainer's GitHub profile. Reports are handled in confidence.

## Enforcement

The maintainer may remove, edit or reject comments, commits, code, issues and other contributions that are not aligned with
this code of conduct, and may temporarily or permanently ban a contributor for behaviour they judge inappropriate, threatening
or harmful. The Contributor Covenant's enforcement guidelines describe the range of responses.
